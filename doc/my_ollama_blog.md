# Ollama本地开源AI大模型快速上手教程
## 简介
Ollama是一款免费开源工具，可以在自己电脑本地跑大语言模型，不需要联网、不用充值，适合学生用来学习AI，写代码、学习答疑。

## 一、下载安装
1. 官网 ollama.com 下载对应系统版本（Windows / Mac / Linux）
2. 双击安装，一路默认下一步，安装完成。

## 二、在终端拉取模型
打开cmd/终端，输入命令，例如：ollama pull llama3
 
 等待下载完成，llama3是轻量好用的开源大模型。

## 三、运行对话
 
ollama run llama3
之后直接输入文字，就可以和本地AI对话。关闭对话输入 `/bye`。

## 四、学生学习用途
- 写代码查bug、学习高数、离散数学、写实验报告
- 断网也可以使用，不会上传你的资料到外网，保护隐私

## 小结
Ollama上手门槛低，适合入门学习本地开源AI，是学生学习AI技术很好的练习工具。
