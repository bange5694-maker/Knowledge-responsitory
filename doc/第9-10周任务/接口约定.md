## 1. Article AI 字段

`blog.models.Article` 新增：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `ai_summary` | `TextField(blank=True)` | `''` | 一句话导读，80–120 字 |
| `ai_highlights` | `JSONField(default=list, blank=True)` | `[]` | 3 个看点 |
| `ai_audience` | `TextField(blank=True)` | `''` | 适合谁读，可空 |
| `ai_keywords` | `JSONField(default=list, blank=True)` | `[]` | 3–5 个关键词 |
| `ai_status` | `CharField(max_length=10, choices=..., default='pending')` | `'pending'` | `pending/done/failed/stale` |
| `ai_generated_at` | `DateTimeField(null=True, blank=True)` | `None` | 生成时间 |
| `ai_model` | `CharField(max_length=50, blank=True)` | `''` | 生成模型 |

状态机：

```text
新建/发布 → pending
生成成功 → done
生成失败 → failed
已生成文章修改标题/正文 → stale
重新生成成功 → done
```

`Article.save()` 规则：

- 已 `done` 的文章，标题或正文变化 → `ai_status='stale'`；
- `save(update_fields=['views'])` / `views` 更新路径不触发 stale；
- 传了 `update_fields` 且不含 `ai_status` 时，保存逻辑会补进去。

## 2. AI Client

包路径：

```python
from djangoblog.ai import AIClient, AIClientError
```

签名：

```python
AIClient.chat(
    messages: list[dict],
    temperature: float = 0.3,
    max_tokens: int | None = None,
) -> str
```

行为：

- 每次调用读取 `settings`，不缓存配置；
- `AI_ENABLED` 假或 `AI_API_KEY` 空 → `AIClientError`，不创建客户端；
- 使用 `openai==2.54.0` 新客户端：
  `OpenAI(api_key=..., base_url=..., timeout=settings.AI_TIMEOUT, max_retries=2)`；
- 调用 `client.chat.completions.create(model=..., messages=..., temperature=..., max_tokens=...)`；
- 返回 `choices[0].message.content.strip()`；
- 空内容 / 上游异常 → 统一 `AIClientError`；
- 不打印、不返回 API Key。

settings：

```python
AI_ENABLED       # 兼容 1/true/yes/on，大小写不敏感
AI_BASE_URL      # 默认 https://api.deepseek.com
AI_API_KEY       # 默认空
AI_MODEL         # 默认 deepseek-chat
AI_TIMEOUT       # 默认 30 秒
AI_MAX_TOKENS    # 默认 800
AI_INDEX_VERSION # 默认 1，缓存版本号
```

## 3. `GET /ai/status/`

用途：前端判断是否注入文章页问答入口。

```text
GET /ai/status/?article_id=<id>
```

响应 200：

```json
{"enabled": true, "article_type": "a"}
{"enabled": true, "article_type": "p"}
{"enabled": true, "article_type": null}
{"enabled": false, "article_type": null}
```

规则：

- `enabled = AI_ENABLED 且 AI_API_KEY 非空`；
- `article_id` 不存在/非数字/未发布 → `article_type=null`；
- 只返回布尔值和 `a/p/null`，不返回模型名、Base URL、Key；
- 不需要 CSRF；
- 前端只在 `enabled=true` 且 `article_type='a'` 时注入入口；请求失败不注入。

## 5. `POST /ai/ask/`

请求头：

```text
Content-Type: application/json
X-CSRFToken: ...
```

请求体：

```json
{
  "question": "这段和缓存有什么关系？",
  "selected_text": "可空，最多 500 字",
  "article_id": 123,
  "include_comments": true,
  "history": [
    {"question": "上一轮问题", "answer": "上一轮回答"}
  ]
}
```

校验：

| 字段 | 规则 |
|---|---|
| `question` | 必填，strip 后非空，≤200 字 |
| `selected_text` | 可空，≤500 字 |
| `article_id` | 可空；有值必须是整数，且是已发布 `type='a'` 文章，否则 400 |
| `include_comments` | 必须是 bool，缺省 true |
| `history` | list，最多 3 项；每项 `{question: str, answer: str}` |

响应 200：

```json
{
  "answer": "……",
  "citations": [
    {
      "type": "article",
      "title": "文章标题",
      "url": "https://.../article/...",
      "snippet": "……"
    },
    {
      "type": "comment",
      "title": "文章标题",
      "url": "https://.../article/...#comment-12",
      "snippet": "……",
      "author": "读者A"
    }
  ],
  "meta": {
    "model": "deepseek-chat",
    "cached": false
  }
}
```

错误：

| 状态 | 场景 |
|---|---|
| 400 | 参数校验失败 |
| 429 | 超过 IP 限流 |
| 503 | AI 未启用、Key 缺失、超时、上游失败 |

## 6. 检索与引用

检索范围：

```text
文章：status='p'
评论：is_enable=True 且所属文章 status='p'
```

数量：

| 模式 | 文章 | 评论 |
|---|---|---|
| 划词 + 提问 | 当前文章 + Top3 相关文章 | Top3 |
| 不划词 | Top5 相关文章 | Top5 |

规则：

- 当前文章始终第一；
- 同一文章最多 2 条评论；
- 文章/评论按来源去重；
- `include_comments=false` 不检索评论；
- 评论只作为“读者观点”；
- 服务端编号 `[S1]`、`[S2]`…；回答里只保留真实来源编号；
- 非法编号丢弃；
- 无有效引用 / 无检索结果 → 固定话术：“站内没有找到相关文章或评论，建议换个关键词”；
- 评论引用 URL：`文章 URL + '#comment-<comment_id>'`。

## 7. 缓存与限流

缓存：

```text
只缓存第一轮、无 history 的问答
TTL = 3600 秒
key = ai_qa:{sha256(question|selected_text|article_id|include_comments)}:{AI_INDEX_VERSION}
命中 meta.cached = true
多轮不缓存
```

限流：

```text
按 IP，10 次/分钟
使用 Django cache，不新增数据库表
超出返回 429
```

- 测试：无 token 403，有 token 200。
