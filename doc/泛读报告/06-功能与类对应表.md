# 5 软件功能与类间的对应关系

> 本节对应模板「5 软件功能与类间的对应关系」，按模板示例表头（序号 / 功能名称 / 实现模块 / 实现方法）列出。

### 表 5-1 软件功能与类对应表

| 序号 | 功能名称 | 实现模块 | 实现方法 |
|---|---|---|---|
| 1 | 首页文章列表 | blog | `blog.views.IndexView`（路由 `blog:index`） |
| 2 | 文章分页 | blog | `blog.views.IndexView`（路由 `blog:index_page`） |
| 3 | 查看文章详情 | blog | `blog.views.ArticleDetailView`（路由 `blog:detailbyid`） |
| 4 | 按分类浏览 | blog | `blog.views.CategoryDetailView`（路由 `blog:category_detail`） |
| 5 | 按标签浏览 | blog | `blog.views.TagDetailView`（路由 `blog:tag_detail`） |
| 6 | 按作者浏览 | blog | `blog.views.AuthorDetailView`（路由 `blog:author_detail`） |
| 7 | 按时间归档 | blog | `blog.views.ArchivesView`（路由 `blog:archives`） |
| 8 | 站内搜索 | blog + Haystack | `blog.views.EsSearchView`（`djangoblog/urls.py` 的 `search` 路由） |
| 9 | 友情链接 | blog | `blog.views.LinkListView`（路由 `blog:links`） |
| 10 | 注册 | accounts | `accounts.views.RegisterView`（路由 `account:register`） |
| 11 | 用户登录 | accounts | `accounts.views.LoginView`（路由 `account:login`） |
| 12 | 退出登录 | accounts | `accounts.views.LogoutView`（路由 `account:logout`） |
| 13 | 找回密码 | accounts | `accounts.views.ForgetPasswordView` + `ForgetPasswordEmailCode` |
| 14 | 第三方登录 | oauth | `oauth.views.authorize` / `oauthlogin`（路由 `oauth:oauthlogin`） |
| 15 | 补充邮箱 | oauth | `oauth.views.RequireEmailView`（路由 `oauth:require_email`） |
| 16 | 发表评论 / 回复评论 | comments | `comments.views.CommentPostView`（路由 `comment:postcomment`） |
| 17 | 评论表情回应 | comments | `comments.views.CommentReactionView`（路由 `comment:comment_react`） |
| 18 | 后台登录与管理入口 | djangoblog | `djangoblog.admin_site.DjangoBlogAdminSite`（`/admin/`） |
| 19 | 文章管理 | blog | `blog.admin.ArticlelAdmin` |
| 20 | 分类 / 标签管理 | blog | `blog.admin.CategoryAdmin` / `TagAdmin` |
| 21 | 友情链接 / 侧边栏管理 | blog | `blog.admin.LinksAdmin` / `SideBarAdmin` |
| 22 | 站点设置 | blog | `blog.admin.BlogSettingsAdmin`（含评论审核开关） |
| 23 | 评论管理 | comments | `comments.admin.CommentAdmin` / `CommentReactionAdmin` |
| 24 | 用户管理 | accounts | `accounts.admin.BlogUserAdmin` |
| 25 | 第三方账号与配置管理 | oauth | `oauth.admin.OAuthUserAdmin` / `OAuthConfigAdmin` |
| 26 | 邮件日志与后台命令 | servermanager | `servermanager.admin.EmailSendLogAdmin` / `CommandsAdmin` |
| 27 | 微信问答 | servermanager | `servermanager.robot.robot`（WeRoBot `make_view`） |
| 28 | 操作日志 | djangoblog | `djangoblog.logentryadmin.LogEntryAdmin` |

> 说明：所有实现方法均在项目源码中可检索；"路由"列为 `urls.py` 中的路由名称，便于与验收测试对照。
